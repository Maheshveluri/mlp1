# Solar Cell Efficiency Prediction (Random Forest)

This project predicts solar cell power conversion efficiency (PCE) from the supplied workbook using **RandomForestRegressor only**. The workbook inspected for this project is `Solar Cell data set.csv.xlsx`.

## Dataset inspection and modeling decisions

- The workbook contains one sheet and, as loaded by Pandas, 42,443 rows and 30 columns.
- `JV_default_PCE` is the continuous target and is reported as a percentage. The dataset contains 924 missing target values and 1,364 duplicate records.
- `JV_measured`, `JV_default_Voc`, `JV_default_Jsc`, and `JV_default_FF` describe electrical measurements associated with PCE. They are excluded from input features to avoid using output measurements to predict the target.
- Duplicate records are removed. Rows with absent, non-numeric, non-finite, or out-of-range PCE (outside 0–100) are removed. Numeric missing values are median-imputed and categorical missing values are most-frequent-imputed inside a scikit-learn pipeline.
- Numeric-like columns stored as text are converted when at least 90% of their non-missing values parse numerically. Other columns are categorical and one-hot encoded. Unknown categories at prediction time are ignored by the encoder.
- An 80:20 train/test split uses random state 42. The top ten features are ranked on a training-only selection subset; a separate training-only subset is used for 3-fold tuning among four Random Forest parameter combinations. The final model is refit on the full training split using those ten features. The Streamlit form and saved model therefore use exactly the same ten inputs.

## Windows setup

Open PowerShell in this project folder and run:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use the environment's Python directly:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Place `Solar Cell data set.csv.xlsx` beside `train_model.py`, or pass its full path. Train and generate evaluation outputs:

```powershell
python train_model.py --data ".\Solar Cell data set.csv.xlsx" --out artifacts
```

Start the prediction interface with the project launcher. It keeps Streamlit's config and machine ID files inside this project folder, which also avoids Windows permission errors in restricted profile folders:

```powershell
.\run_app.ps1
```

The app creates fields from the model's saved feature list. Blank fields use the training pipeline's imputer, numeric fields are validated, and unknown categories are safely handled. The artifacts contain the model, test metrics, actual/predicted values, dataset analysis, and charts.

After prediction, the app also looks for an exact match across all ten inputs in `actual_efficiency_lookup.csv`. It displays the recorded PCE when the match is unique, or the observed range and values when multiple source rows share the same ten features. For input combinations absent from the dataset, actual PCE is unavailable until measured.

## Evaluation metrics

- **R²:** how much variation in the test-set target is explained by predictions. A value closer to 1 indicates closer fit; it can be below zero.
- **MAE:** average absolute prediction error in PCE percentage points.
- **MSE:** average squared prediction error, which gives larger errors more weight.
- **RMSE:** square root of MSE, again in PCE percentage points.

The metrics are generated from the actual held-out test set when `train_model.py` completes. They are not hard-coded.
